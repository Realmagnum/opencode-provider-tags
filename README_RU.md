> **Разделение дублирующихся названий моделей в OpenCode Desktop через добавление коротких меток провайдеров.**  
> *Disambiguate duplicate model names in OpenCode Desktop model picker by appending short provider tags.*

---

## 📖 Описание / Description

При подключении нескольких кастомных или локальных провайдеров моделей в OpenCode (таких как **Antigravity**, **Antigravity Manager**, **llama-swap**, **cpamp**, **OpenRouter**, **Polza.AI**), в меню выбора модели (`Ctrl+/` или `Cmd+/`) часто появляются одинаковые имена (например, несколько позиций с именем `Claude Opus 4.6 (thinking)` или `Gemini 3.8 Flash (tiered)`). Из-за этого сложно понять, через какой именно эндпоинт пойдёт запрос.

**opencode-provider-tags** решает эту проблему, аккуратно добавляя короткие настраиваемые суффиксы к отображаемым именам моделей:
* `Gemini 3.8 Flash (tiered) [AGM]` *(Antigravity Manager)*
* `Gemini 3.8 Flash (tiered) [AG]` *(Antigravity)*
* `claude-opus-4-6-thinking [CPAMP]` *(CPAMP)*
* `Bonsai 2 27B [LS]` *(llama-swap)*

## ✨ Возможности

- **Нативная страница настроек SolidJS:** Встраивается в окно настроек OpenCode Desktop (`Cmd+,` / `Ctrl+,`) отдельным разделом **`Метки провайдеров (плагин)`** / **`Provider Tags (plugin)`** с акцентным цветом иконки (`#9d7cd8`) и аккуратным бейджем `[Plugin]`.
- **Быстрый переход по кнопке-шестерёнке:** В списке `Extensions` -> `Plugins` автоматически добавляется иконка-шестерёнка (`16px`) перед кнопкой `Reload` для мгновенного перехода в настройки плагина.
- **Интерактивный предпросмотр (Live Preview):** В верхней плашке в реальном времени показывается, как модель будет выглядеть в меню выбора.
- **Строгая валидация меток:**
  - Ограничение длины (до 12 символов).
  - Разрешённые символы: буквы (`a-z`, `A-Z`, `А-Я`, `а-я`), цифры, `_`, `-`, пробел и квадратные скобки `[]`.
  - Проверка закрытости скобок.
  - Автоматическая проверка на дубликаты меток между провайдерами с подсказкой коллизий.
- **Заполнение по умолчанию в один клик:** Встроенные пресеты для популярных сервисов (`[AG]`, `[AGM]`, `[CPAMP]`, `[SS]`, `[LS]`, `[Polza]`, `[OR]`).
- **Безопасное ручное применение:** Все изменения остаются в состоянии черновика до явного нажатия кнопки **«Применить»**.
- **Сброс к каноническому виду:** Кнопка «Сбросить к каноническому виду» возвращает всем моделям их оригинальные чистые имена без суффиксов.
- **Сохранение комментариев и форматирования JSONC:** Модификация конфигурации производится через официальный `jsonc-parser` от Microsoft, поэтому комментарии (`//`, `/* */`), отступы и секции других плагинов не затираются.
- **Защита внешних изменений:** Умный алгоритм распознавания канонических имён автоматически определяет, если модель была переименована или добавлена извне (например, через Antigravity Manager), исключая перезапись актуальных данных старыми кэшами.

## 📦 Установка

### Вариант 1: Локальное клонирование (Рекомендуется)

Склонируйте репозиторий в каталог плагинов OpenCode:

```bash
git clone https://github.com/Realmagnum/opencode-provider-tags.git ~/.config/opencode/plugins/provider-tags
```

*(В Windows путь: `%USERPROFILE%\.config\opencode\plugins\provider-tags`)*

OpenCode Desktop V2 автоматически находит локальные плагины в `~/.config/opencode/plugins/`.

### Вариант 2: Подключение через конфиг

Или добавьте путь в массив `plugin` вашего `~/.config/opencode/opencode.jsonc`:

```jsonc
{
  "plugin": [
    "opencode-provider-tags"
  ]
}
```

После этого обновите интерфейс по `Ctrl+R` или `/reload`.

## 🛠️ Использование

1. Откройте настройки OpenCode Desktop (`Cmd+,` на macOS или `Ctrl+,` на Windows/Linux) либо нажмите на ⚙️ шестерёнку в `Extensions` -> `Plugins`.
2. Выберите в боковом меню раздел **Метки провайдеров (плагин)**.
3. Включите тумблер **Включить суффиксы для моделей**.
4. Задайте короткие метки для каждого провайдера или нажмите **Заполнить по умолчанию**.
5. Нажмите кнопку **Применить**. Конфигурация применится мгновенно без перезапуска OpenCode.

## 🏛️ Архитектура и безопасность

- **Обход Electron CSP/CORS:** Архитектура плагина разделена на UI-слой (рендерер окна SolidJS) и защищённый процесс Node.js (`main`), связь между которыми работает через типизированный IPC-контракт (`@opencode/plugin/gui`).
- **Резервные копии:** Перед каждой модификацией `opencode.jsonc` плагин автоматически создает аварийную копию (`opencode.jsonc.bak-before-apply` / `opencode.jsonc.bak-before-reset`).
- **Очистка сиротских тегов:** Если провайдер удаляется из `opencode.jsonc`, плагин безопасно очищает его метку и не выдает ложных ошибок дубликатов.
